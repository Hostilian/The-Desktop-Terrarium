# Screenshot Guidelines

This directory `docs/screenshots/` is used to store high-quality images of the application for documentation, the README, and marketing materials.

## Required Screenshots

Please capture the following screenshots and save them in this folder with the specified filenames:

1.  **`main-view.png`** (1920x1080)
    *   **Content:** A bustling terrarium (Forest type) in daytime.
    *   **UI:** Statistics window OPEN (F3), Mini-map OPEN (M).
    *   **Action:** Lots of plants and animals visible.

2.  **`statistics.png`** (1280x720)
    *   **Content:** Focused view of the Statistics overlay.
    *   **Action:** Showing a thriving population graph.

3.  **`factions.png`** (1920x1080)
    *   **Content:** A world split between two or three factions (e.g., Red vs Green).
    *   **Action:** Show territory borders clearly.

4.  **`god-powers.png`** (1280x720)
    *   **Content:** Action shot of a god power being used (e.g., Lightning strike or Rain).
    *   **Action:** Particle effects visible.

5.  **`chronicle.png`** (1280x720)
    *   **Content:** The Chronicle window (F4) showing a list of interesting history events.

## Tips for Great Screenshots

*   **Hide the mouse cursor** if possible (or move it out of the way).
*   **Use High Graphics Quality** in Settings (F2) before capturing.
*   **Turn off debug overlays** unless specific to the screenshot.
*   **Wait for a nice composition** - don't rush!
